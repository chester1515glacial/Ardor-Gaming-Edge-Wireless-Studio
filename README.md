**Ardor Edge Audio Studio** — это полноценная неофициальная панель управления звуком и микрофоном для беспроводной гарнитуры **ARDOR GAMING Edge Wireless**. 

В отличие от проводной версии наушников, беспроводная модель (`Edge Wireless Black`) не имеет собственного фирменного ПО. Из-за этого владельцы сталкиваются с глухим звуком «из бочки» и тихим, плоским звучанием микрофона по радиоканалу. Эта программа решает обе проблемы в едином удобном интерфейсе, полностью заменяя связку из сторонних тяжелых программ (*FxSound* + *Voicemeeter*).

---

## 🔥 Ключевые возможности 

Программа работает как графический центр управления реального времени над системным драйвером **Equalizer APO**, обеспечивая **нулевую задержку звука (0 мс)** и полное разделение потоков динамиков и микрофона:

### 🎧 1. Вкладка `Speakers` (Наушники и Эквалайзер)
* **10-полосный графический эквалайзер** (`30 Гц – 16 кГц`) с мгновенным откликом в реальном времени.
* **5 готовых пресетов звучания:**
  * `FxSound Voice` — главный профиль: полностью убирает заводской эффект «звука из банки», очищает гудящий бас и раскрывает чистоту середины и верхов.
  * `Музыка / Рок` — плотный бас с подчеркнутыми гитарами и вокалом.
  * `Шаги / Игры` — спецпрофиль для соревновательных шутеров (акцент на диапазоне 1–4 кГц для четкого позиционирования шагов, перезарядки и звуков способностей).
  * `Bass Boost` — мягкое усиление низких частот без хрипа динамиков.
  * `Default (Сток)` — чистый заводской звук.
* **Блок тонкой доводки:** отдельные ползунки **«Усиление баса (Низы)»**, **«Четкость звука (Clarity)»** и **«Динамика / Громкость»**.

### 🎙️ 2. Вкладка `Mic` (Студийный голос и Шумодав)
* **Изолированная обработка микрофона:** переключение режимов и настройка ползунков микрофона работают строго на канал записи и **никак не затрагивают звук в наушниках**.
* **Цепочка фильтров `Радио-Бас + Чёткость (PRO)`:**
  * **High-Pass фильтр (`< 85 Гц`):** срезает низкочастотный гул кулеров ПК и бытовой шум.
  * **Грудной Радио-бас (`135 Гц`):** придает голосу бархатную глубину и объем (эффект студийного бродкаст-микрофона).
  * **Подавление «коробочного» призвука (`340 Гц` и `800 Гц`):** убирает пластиковый и глухой оттенок беспроводного передатчика.
  * **Кристальная дикция (`3.4 кГц` и `6.2 кГц`):** делает речь разборчивой, звонкой и чистой в Discord и игровом чате.
* **Умный шумодав (`Audibility Gate`):** автоматически отсекает фоновый шум комнаты, клики мышки и стук клавиатуры, когда вы молчите.
* **Кнопка «🔊 Прослушать себя»:** мониторинг своего голоса в реальном времени прямо во вкладке микрофона для быстрой настройки под свой тембр.

### ⚙️ 3. Удобство и системная интеграция
* **Установщик «Всё-в-одном» (x64):** сам устанавливает программу, при необходимости ставит движок *Equalizer APO* и автоматически выдает права доступа к конфигурационным файлам (не требует запуска от имени Администратора).
* **Защита от повторного запуска (Single Instance Mutex):** программа никогда не запустится в двух экземплярах одновременно.
* **Работа в системном трее:** сворачивается в значок возле часов при закрытии окна, не занимая место на панели задач.
* **Автозапуск с Windows** по одной галочке в шапке окна + автосохранение всех пользовательских настроек в `%APPDATA%\ArdorEdgeStudio\settings.json`.

## 📥 Установка и первый запуск

1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте установочный файл **`ArdorEdgeStudio_Full_Setup.exe`**.
2. Запустите установщик:
   * Если вы устанавливаете программу впервые и у вас еще нет *Equalizer APO*, оставьте галочку **«Установить звуковой драйвер Equalizer APO»**.
   * В финале установки отметьте пункт **«Настроить привязку к наушникам (Configurator)»**.
3. В открывшемся окне **Configurator** один раз привяжите драйвер к гарнитуре:
   * На вкладке **Playback devices** (Воспроизведение) поставьте галочку напротив **`Динамики / Speakers (Edge Wireless Black)`**.
   * На вкладке **Capture devices** (Запись) поставьте галочку напротив **`Микрофон / Microphone (Edge Wireless Black)`**.
   * Нажмите **OK** и **перезагрузите компьютер** (требуется только один раз после установки драйвера).
4. Запустите **ARDOR GAMING Edge Studio** с ярлыка на Рабочем столе!

> 💡 **Важно:** Перед использованием отключите сторонние программы-улучшайзеры (*FxSound*, *Voicemeeter*, *SteelSeries Sonar*), чтобы эффекты не накладывались друг на друга дважды. В Discord и играх выбирайте стандартное устройство: `Микрофон (Edge Wireless Black)`.

## 🎚️ Шпаргалка по настройкам

| Вкладка / Ползунок | За что отвечает | Рекомендуемая настройка |
| :--- | :--- | :--- |
| **Пресет эквалайзера (`Speakers`)** | Базовая кривая звучания наушников | `FxSound Voice` (универсальный) |
| **Усиление баса (Низы)** | Плотность низких частот (60–120 Гц) | `-3.5 дБ` (чистый звук) / `+2.0 дБ` (мощный бас) |
| **Четкость звука (Clarity)** | Детализация высоких частот (4–8 кГц) | `6` из `10` |
| **Режим микрофона (`Mic`)** | Профиль обработки вашего голоса | `Радио-Бас + Чёткость (PRO)` |
| **Шумодав (Audibility Gate)** | Порог тишины (отсечение клавиатуры и фона) | `3.0` (поднимите до `4.5`, если вокруг шумно) |
| **Глубина голоса (Радио-бас)** | Насыщенность и «бархатность» тембра | `+3.5 дБ` |
| **Чёткость речи** | Звонкость и разборчивость голоса | `+6.0 дБ` |
| **Усиление громкости (Gain)** | Общая громкость микрофона | `+2.0 дБ` (до `+6.0 дБ`, если вас тихо слышно) |

## 🛠️ Сборка из исходников (Для разработчиков)

Требуется **Python 3.10+ (64-bit)**.

1. Установите необходимые библиотеки:
   ```bash
   pip install customtkinter sounddevice numpy pillow pystray pyinstaller
   ```
2. Запустите скрипт для генерации фирменной иконки `ardor_icon.ico`:
   ```bash
   python ardor_hub.py
   ```
3. Соберите исполняемый `.exe` файл:
   ```bash
   python -m PyInstaller --clean --noconsole --onefile --icon=ardor_icon.ico --name="ArdorEdgeStudio" ardor_hub.py
   ```
4. Для сборки инсталлятора откройте файл `ardor_setup.iss` в **Inno Setup Compiler** и нажмите **F9**.
